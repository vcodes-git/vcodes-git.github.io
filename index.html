2.13D Architectural Reconstruction Pipeline

Python, COLMAP, computer vision, NumPy Apr 2026 · repo ↗
  • Eliminated fragmented point cloud failures by replacing sequential brute-force matching with a temporal window-based approach and KD-tree indexed ANN search, reducing matching complexity from O(N²) to O(N log N).
  • Wrote a script to inject verified matches into COLMAP's SQLite database, correcting radial distortion via OpenCV-to-PINHOLE conversion and applying SOR and DBSCAN outlier removal to achieve sub-pixel reprojection accuracy (0.421px).
  • Implemented 3D Gaussian Splatting over 30,000 iterations initialized from the cleaned sparse point cloud, achieving under 2.3% geometric error on window dimensions verified against real-world measurements.
